# 元素定位

## HTML标签

所有的Web系统，所谓的前端，其实就是HTML和JS。前端其实也就是人肉眼可见的界面。无论页面长啥样，所有一切的内容都是基于元素的形态来实现展示的。不同的元素其实就是一个个不同的HTML的标签。

HTML本身是一种标记语言。整体的结构是基于树状结构栏来实现的。所有的标签都是有自己的父级和子级节点存在，基于整个页面的结构来决定。

所有的标签都是基于三个部分来组成的。标签名、标签属性、标签文本。每一个元素不是必须要有完整的三部分。

1. 标签名：决定了元素的类型或者内容。常见的标签：a、input、div、span。。。。。。
   1. 任何元素在获取和操作时，只基于标签名来决定是否可行。其余一切都不重要。
2. 标签属性：可以有多个属性存在。不同的属性之间通过空格来进行分离。属性赋值通过=来进行。所有的属性都是包含在<>之中的。在标签名之后的。属性本身是可以有值也可以无值。
3. 标签文本：在元素的尖括号以外的内容。一般常见于超链接，span等标签之中。文本是可有可无的。
4. 标签模板：<标签名称 属性1="value" 属性2="value2">标签文本</标签名称>或者<标签名称 属性1="value" 属性2="value2"/>

日常在网站里看到的所有内容，是由不同的元素来组成的。不同元素的样式大多数时候都是基于元素的class属性来决定的。而且元素本身的内容也是基于标签内容来决定。所以眼见不一定为实。一切都以HTML的内容作为决定。至于说页面长啥样，这是前端决定的，不是测试需要考虑的问题。

## 八大元素定位法则

所有的元素在操作之前，一定要先获取。而获取元素叫做元素定位。元素定位常见有八大法则：

1. id
2. name
3. classname
4. tagname
5. link text
6. partial link text
7. css selector
8. xpath
