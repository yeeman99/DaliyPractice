# SMTP库实现邮件发送

## SMTPLIB服务配置

自动化邮件发送，是自动化测试过程中对于结果的产出方式。在实现邮件自动发送的功能时，一定需要将邮箱的相关配置全部都存放在代码之中。

不通邮件的配置是不一样的。你需要用到什么类型的邮箱，则可以提前网上搜一下对应的邮箱配置即可。课堂是使用QQ邮箱来实现案例。

1. 登录邮箱
2. 进入到设置页
3. 启动smtp服务（默认为关闭状态，第一次开启需要手动验证）
4. 获取授权码（授权码不是密码。与账号密码无关）
5. 保存授权码到本地，以方便后续的正常使用
