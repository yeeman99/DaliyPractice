# Pytest基本应用

## Pytest环境部署

Pytest可以是UnitTest的进阶版。UnitTest下的所有内容都可以基于Pytest来进行执行。Pytest本身的第三方库会更加的丰富，内容的实现上会自由度更高。

自动化鄙视链：Pytest——UnitTest——TestNG——RobotFrameWork。其实在实际应用过程中，pytest和UnitTest还是市场主体，所以我们没有办法选择企业用什么技术。所以我们都掌握。

pytest本身和UnitTest类似。都是作为用例的管理以及第三方测试报告生成的模块。

pytest环境部署：pip install pytest

校验环境安装成功与否：在cmd中输入pytest--version来校验环境安装是否正常。

pytest本身的功能非常非常多。如果有兴趣可以了解官方的API，我们在课程中只是讲解其中最常用的部分。用于解决常规问题，如果说你有特定的需求，可以提前在官网进行了解。

## Pytest基本应用讲解

pytest本身的设置是可以修改的。所有的设置都是有默认值存在的：

1. 所有的测试文件（py文件）必须是满足test\*.py的命名格式来实现。其实也可以通过\*test.py的规则来实现，但是这种方式不推荐。
2. 所有的测试类和用例的名称都必须以test开头。类名就是Test\*，用例就是test\*
3. 在pytest中，有很多功能可以来实现用例的增强，这些增强功能绝大部分情况下都是基于装饰器的形态来完成的。所以如果需要有任何增强的功能，优先考虑装饰器的内容。
4. pytest是通过命令行来实现指令的执行。
