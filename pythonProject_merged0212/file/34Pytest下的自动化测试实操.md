# Pytest下的自动化测试实操

## pytest下的自动化测试用例结构设计

1. 实现一个全新的自动化测试，一定是基于一个新的工程来单独管理整个自动化测试。
2. 记得各类分离的规则。每一个不同的文件夹（路径）都有属于自己的独有功能。所以分层可以让我们更好地进行整个结构的规划和管理。
3. 测试用例的设计。用例的核心点就是Fixture。因为Fixture在实际测试过程中可以为我们提供非常多的帮助。
4. 如果要基于Allure来实现测试报告的生成。就一定要通过学习到的Allure装饰器来丰富测试报告的内容。让测试报告变得更加完整。

## 课后作业

1. 实现基于关键字驱动的自动化测试。
2. 基于POM。设计自己的Pytest+Allure的自动化测试。
3. 一套测试框架满足多个不同环境下的自动化测试执行该如何设计。（测试环境和线上环境，在接口测试解决）
