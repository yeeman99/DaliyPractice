# 日志logging库的应用

## 日志的基本应用

在Python编程过程中，需要频繁通过logging库实现对需要记录的内容进行记录的操作。

在自动化测试执行过程中，我们不可能说通过人为类似站岗的方式来观察整个自动化测试过程是否正常。所以我们需要有一个第三方的角色来帮助我们记录整个测试的过程。这个时候就需要使用到日志的功能。所以如果出现问题，日志可以第一时间记录下来。以便于后续我们来进行问题的排查与追踪。

python中日志记录的核心库是官方自带的logging库。

## 日志的进阶使用

logging库应用，其核心其实就是四个组件：

1. logger记录器
2. handler处理器
3. filter过滤器
4. formatter格式化器

## 配置文件设置与读取

因为logging库本质上就是对所有的内容进行配置操作。并且所有的设置基本都是固定的。在实际应用的时候基本上只需要定义一次即可。后续可以一直重复来进行使用。所以可以将所有的设置内容通过配置文件进行相关的设定管理。然后再通过logging来实现内容的获取。

文件路径可以通过pathlib库来获取
