# DDT+Yaml数据驱动实现

## DDT应用与原理

数据驱动是用于管理复杂的数据情况而实现的一种数据管理手段。如果是简单的数据，直接可以写入代码之中，没有必要为了数据驱动而做数据驱动。

ddt全称叫做Data Driver Test，数据驱动测试模块。ddt本身只做简单数据的管理。复杂数据不基于ddt管理。但是可以通过ddt导入。ddt属于第三方模块。所以需要通过pip install ddt的指令来进行安装。

ddt在UnitTest中的使用是基于装饰器的形态来实现的。

## Yaml语法结构与基本应用

yaml是一种文件格式。一般常用于自动化测试数据管理和系统程序的配置文件进行使用。所有后缀名为yaml、yml的文件，都是yaml文件。它属于一种非常灵活轻便的文件。具备有自己的格式要求。

常规的测试数据，从文件读取之后一般都是需要做数据处理的。但是yaml则不需要。因为yaml可以直接实现int和str的明确区分，以及直接传入list或者dict数据格式的内容。极大地减少了有关于数据管理的行为。可以让整个测试过程更加简单。

yaml的安装需要通过pip install pyyaml来实现。

### 语法规则

yaml本身是一种对缩进非常敏感的语法结构。所有的数据内容和上下级关系都是基于缩进来进行控制和管理。就类似于Python

1. list格式的数据一定是- 的结构来实现的，一定记得在-后面有一个空格存在。
2. 默认情况下所有的数字都为int类型，如果想要在yaml中将数字变为str，则记得在数字上添加一组引号。
3. dict格式的数据一定是key: value的结构来实现的，一定记得在key:后面有一个空格的存在
4. 字典和list是可以相互嵌套的，前提条件是你需要注意yaml文件的语法结构规则即可。

## Yaml锚点与引用

锚点其实就是类似于变量的概念。我们可以提取yaml中的公共部分的内容，作为锚点，在后续其他组数据的编写过程中，通过引用锚点的方式将重复的数据引入。让整个yaml的数据结构可以变得更加精简。

语法规范：

- 锚点：通过用&来定义。
- 引用： 通过*锚点名称来进行 锚点的引用
- 追加：通过<<来进行内容的追加
