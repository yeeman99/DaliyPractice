# Pytest测试用例管理

## Pytest测试用例

Pytest下的测试用例，在整体管理和执行上，基本与UnitTest没有太大差异。

常见的测试管理上，我们可以通过skip装饰器实现对用例的跳过管理。

## Mark装饰器与Parametrize装饰器应用

### Mark装饰器

在Pytest中，可以通过mark装饰器来实现对不同用例进行分类设置和管理的功能。实现对用例的细化管理。方便我们区分不同的业务场景所需执行的测试用例。满足我们各类测试场景的实际需求。整体基于@pytest.mark装饰器实现。

### Parametrize装饰器

实现对用例进行数据驱动的功能。
