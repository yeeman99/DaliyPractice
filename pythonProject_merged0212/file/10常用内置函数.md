# 常用内置函数

## 反射机制

反射机制，属于Python中独有的一种特殊机制。就是通过字符串来驱动代码的一种逻辑形式。以字符串的形态来实现对对应模块的方法、属性的调用。通过反射机制可以极大地去减少代码的逻辑。也可以让我们以动态的形式来实现代码的处理能力。

在Python中，反射机制其实就是四个不同的函数：

1. gettattr()
2. setattr()
3. hasattr()
4. delattr()
