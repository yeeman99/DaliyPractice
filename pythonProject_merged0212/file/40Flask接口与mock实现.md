## Mock实现

mock，也叫做mock server。其实就是所谓的模拟服务。

mock：

1. 属于接口测试过程中相对有一定进阶的技术体系。
2. 在测试执行过程中，经常容易出现一些接口无法正确执行的问题。通过mock来模拟接口的数据，从而让整个接口业务流程可以正常的执行测试。
3. 在实际测试过程中，对于第三方接口我们也能通过mock来实现关联接口的测试需要。
4. 在实际测试过程中，有可能会遇到业务流程极其复杂的测试流程。或者说需要调用很多的接口来生成关联数据。所以为了考虑去掉不必要的操作行为。可以直接通过mock来解决前期的测试数据的生成

mock只是接口测试过程中的一种手段而已。方便我们可以更好地执行完整的接口测试行为。
