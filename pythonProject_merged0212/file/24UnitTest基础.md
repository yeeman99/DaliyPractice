# UnitTest基础

## UnitTest介绍

UnitTest依旧还是目前市场主流使用的测试用例管理框架之一。UnitTest在实际应用的过程中，主要就是用于管理测试用例的。属于测试框架的核心模块之一。

UnitTest的四大组件，也是它的核心：

1. 前后置条件：测试执行过程中需要提前准备的内容，叫做前置条件。测试结束之后需要进行的相关操作，叫做后置条件 。所有与测试本身无关的行为，但是又是必须要执行的行为，我们可以统一在前后置中进行管理。
2. 测试用例：所有的测试流程都基于测试用例来进行统一管理。UnitTest中对于测试用例有自己的独特语法结构和使用方法。
3. 断言机制：UnitTest中自己封装有非常多成熟的断言方法。可以直接调用，不需要再额外进行封装。
4. 套件与运行器：
   1. 套件：用于批量管理测试用例。
   2. 运行器：用于生成测试报告。

UnitTest是Python官方库，在安装Python的时候默认就已经有了。不需要进行额外的安装。直接导入使用即可。
