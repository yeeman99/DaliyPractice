# Json与JsonPath应用

## Json与Restful

json是一种非常常见的数据格式。常见于接口的响应结果和请求数据之中。基本上绝大多数的接口通信的数据都是基于json格式来实现交互的。

json的数据格式特点：{"name":"hcc"} 类似于字典的格式。只是说所有的key和value都是基于双引号括起来的字符串。int则没有引号。整个数据的类型是字符串str。无法直接通过key获取value。需要通过数据的处理之后才可以通过key来获取value。

整体json的数据内容传递，可以通过post请求中的json参数来实现数据的传递，也可以在请求头设置Content-Type来实现json的格式定义。需要提前通过接口文档确认接口的数据通信是否是以json作为传输格式。

Restful：其实就是一种规范。不是协议。是一种基于http网络协议实现的数据传输格式的规范定义。用来定义数据的格式，而非一种新的技术。按照统一的格式来保障请求数据以及响应结果的内容的展示。仅此而已。只要你的系统是按照一种统一的格式来实现数据传输的话，则可以将你的系统称之为基于Restful规范实现的数据通信。

目前市场上基于Restful规范实现的数据通信绝大多数都是以json格式来实现的。

案例：

- 基于嘴的沟通来实现奶茶的需求和购买。
- 通过购买回执单来实现客户奶茶的确认。
- 所有员工对于客户的需求以及回执单的编写有自己的习惯和喜好。回执单就千奇百怪。
- 重新定义了回执单的内容：
  - 单号
  - 商品，单价，数量，总价
  - 客户特殊喜好
  - 购买时间
  - 会员卡号
  - 当前余额
  - 积分
  - 会员信息

这就是Restful。通过定义一套统一的规范，从而实现数据的固定通信模式。目前主流的模式就是基于json实现的。

## Json常用函数讲解

python中有专门处理json格式数据的库。官方自带的，叫做json库。关于json的所有操作，基本上这个库可以完全满足了。

## JsonPath解析Json内容

jsonpath专门用于解析json的格式内容。因为json格式一旦内容增加之后，在获取某些数据时会变得非常的麻烦。jsonpath就是把复杂的事情变得简单的一种手段。

jsonpath整体类似于xpath的概念。通过类似于路径的方式来获取到指定值的一个库。

安装：pip install jsonpath
