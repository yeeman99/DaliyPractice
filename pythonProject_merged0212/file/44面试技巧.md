# 面试技巧

## 面试流程

- 面试前
  - 查看公司的招聘信息，了解公司具体的招聘岗位需求是什么。以便于更好去准备这一次的面试。
  - 查看公司的本身信息。出于安全考虑，避免不必要的麻烦。熟悉公司的核心产品信息。
  - 个人的装扮，素雅大方得体即可。
  - 把缺失的技能，能够补足的基础知识好好补足一下。
- 面试中
  - 面试记得提前到
  - 笔试是可以抄资料的，如果遇到不会的，大方拿手机看资料。
  - 面试流程：自我介绍——聊项目——聊技术——聊薪资——提问——结束
    - 自我介绍
      - 可以提前准备，但是不要死记硬背
      - 介绍内容挑重点说，时间控制在三分钟以内。
      - 突出你个人的经历、学历、擅长的技术能力等相关方面，参与过的厉害的项目之类的内容。都可以聊
    - 聊项目：面试官感兴趣的项目
      - 介绍项目本身的背景和核心业务
      - 着重讲解个人在项目中实际参与的测试工作内容
    - 技术交流：基于项目和你聊相关的技术内容，以及通过技术内容发散更多的内容
      - 你会的技术
        - 结合你的实际业务来进行技术的详细讲解
      - 你不会的技术
        - 完全没有接触过的技术，就直接说我不会。
        - 如果是某个点的技术你不会，可以通过平替来进行技术的讲解
      - 一定要搞清楚面试官的问题。他到底想要知道什么？（如果摸不透，可以再次询问一下）
    - 聊薪资：不要和任何人比较
      - 明确你自己的薪资目标
      - 薪资是基于整体面试的过程来评估的。
      - 大方谈，不要害羞。
    - 提问：
      - 一定要提问
      - 通用提问模板：
        - 贵公司研发团队规模如何，测试团队规模如何
        - 如果入职贵公司，我主要负责的工作核心内容是什么
        - 围绕产品进行针对性的提问
      - 雷区避免：
        - 贵公司加班多不多
        - 是不是有拖欠工资
        - 有投诉，有劳动纠纷
        - 五险一金是不是正常缴纳
        - 贵公司的产品是什么
  - 面试注意点：
    - 面试是一种双向选择的合作协议形态。不需要太过于卑微了。
    - 面试的时候不要太过于随意。还是稍微端着点。
    - 沟通过程中一定记住声音保持在相对平稳的状态，不要忽大忽小。也不要过大过小。
- 面试后
  - 自我总结，避免在后续的面试中犯同样的错误。不要拿特例当做常规。
  - 到了约定时间，如果对方没有联系你，记得主动询问一下。
    - 如果面试不通过，起码你知道不通过的原因在哪里。

## 面试心理学

1. 所有面试的小花招都是附加值，核心在于面试时你的实力表现。
2. 所有问题一定要清楚了，听懂了再回答，保持彼此的沟通效率和氛围。
3. 沟通时避免口头禅和语气用词。同时避免过于结巴。
4. 学会观察
5. 不要背诵任何内容。
6. 主动权的夺取：面试过程中谁提问谁有主动权。学会适当的夺取主动权，但是分人而异。
