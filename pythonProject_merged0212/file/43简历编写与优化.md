# 简历编写与优化

## 简历编写关注点

- 如果说现在已经写好简历，投递的时候也有不错的面试机会。那说明你的简历没有问题，不需要额外再去做其他优化。如果没有这种情况，则好好思考一下你的简历问题。
- 我们需要的是offer，不是面试。
- 不要有任何精神内耗，认准目标就好了。
- 如果你真的很纠结，很难受，不知道方向，那就按照我的说法一个字一个字地去执行就好。
- 所有的工作，都是基于简历开始的。简历的内容一定要写的细致且完整。后期靠你的人脉圈子。靠你的自身口碑的积累才行。
  - 包装，一定要在自我认知清晰的情况下再包装。把会的东西可以适当包装，不会的不要写。
  - 简历模板不要花钱买，直接在招聘平台用在线简历即可。
  - 找工作这件事情，其实就是看你的技术能力和过往经验。没有所谓很难的情况。现在投递简历基本是两个月左右的时间才会有结果。运气好点的人可能会短一些。
    - 包装公司：安行云图，也就是ccas的开发公司。
- 简历的编写：
  - 基本信息
    - 学历：专科及以上。学历越高越好。平台越大的公司越看重员工的学历。对于学历不自信的同学，可以考虑学历的二次提升。虽然含金量不高，但是听起来像那么回事。注意不要提升民办学历。
    - 年龄：30岁以下，相对友好。越年轻越好。30岁以上，相对难度会大很多。所以需要其他方面来补足一下。28岁及以上的女性，如果未婚未育，你很危险。要自己想好理由。
    - 照片：女性学员，挂照片请发给我帮你审核。
  - 专业技能
    - 这是你简历最值钱的部分，也是你能否获得更多面试邀约的核心点。
    - 技能一定要把值钱的部分突出，技能一定要把会的东西有细节。
    ```python
    # 简历示例
    精通黑盒测试，精通测试流程，熟练使用各种黑盒测试手段实现对系统的测试行为
    熟练使用各类测试工具，满足测试需求
    熟悉业务测试执行流程
    了解python自动化
    .....
    
    # 细化能力，突出能力
    1. 简历不写精通。
    2. 不值钱的内容不需要花费太多的篇幅来描述
      细化版本：
        1. 熟练掌握Python+Selenium实现的UI自动化测试能力，能够基于关键字驱动设计
        模式结合各类数据驱动，基于系统业务需求来完成WebUI自动化测试框架的搭建和部署
    3. 不会的东西千万不要写。宁肯内容少点，也不要给自己挖坑。
    ```
  - 项目经验
    - 简历第二值钱的内容
    - 项目一定要和你的专业技能关联上。因为面试的核心其实就是基于项目业务来体现你的技术。
    - 面试官不是你同事，不知道你的项目实际情况。
    - 内容：
      - 项目介绍：介绍这是个什么项目，做什么的，解决什么问题的。
      - 个人职责：很重要。体现你在项目中做了什么。越多越好
      - 个人能力体现在你项目参与的程度.所以参与越多,越能体现你在上家公司的重要性.这是非常加分的事情
    - 一封简历项目写三个左右即可，不用写太多。写太多一方面是时间过于久远，另外是面试官也没有兴趣看那么多。
      - 一般选择，最新的项目，规模最大的项目，业务最复杂的项目。
      - 如果没有项目经验，现在可以使用ccas作为你的项目经验，后续其他项目上线后会及时通知。
  - 其他
    - 工作经验：
      - 时间轴要对应上。
      - 空窗期，不超过六个月都不算空窗期。随便找理由搪塞过去即可。超过的要认真思考一下如何包装简历。
      - 应届生本来就没经验，所以可以忽略。如果有实习经验记得写上。
      - 转行的，请参考包装这一栏。
    - 自我评价：
      - 如果不是应届生，可以不用写。
      - 大家就是过来上班的，不是过来社交的。社交是附带价值。

## 简历优化方向

1. 一定突出重点。让自己值钱的东西可以无限放大。
2. 一定要有行业核心技术能力。
   1. 优先满足核心技术能力要求，你才可以找到工作
   2. 满足更多的附加值，你才可以有更好的工作
3. 简历优化不是万能药。不能解决所有的问题：
   1. 市场投递简历，两周起步。海投
   2. 找工作预留两个月时间
   3. 因为找工作真的很靠运气
