# PyMysql库实现数据库操作

## PyMysql环境部署

 针对mysql数据库实现代码操作的第三方库。所以我们需要提前安装PyMysql库。

- 启动cmd
- 输入pip install pymysql即可实现安装。如果有需要记得切换国内源
- 友情提醒，如果需要通过PyMysql库实现对mysql数据库的操作，记得在本地提前安装好mysql

## PyMysql操作数据库

提供有针对mysql数据库相关联的操作，比如日常所需要的基本增删改查都会有完整关联。数据库本身的操作最核心的就是查询。一般我们也会通过PyMysql来实现对于数据的查询操作。包括自动化测试，其核心就是查询以及获取数据库中存有的数据。
